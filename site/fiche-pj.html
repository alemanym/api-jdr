Mode d'emploi
  • Charger : désignez une fois le dossier des fiches (Personnages/pj/ ou la racine du projet, le sous-dossier est détecté). Le dossier est mémorisé dans ce navigateur ; à la prochaine ouverture il suffit de ré-autoriser l'accès.
  • Valeurs courantes (PV, chance, PA, capsules, munitions, poids porté, objets, statut…) : un clic ouvre la saisie. Entrée ou sortie du champ valide ; Échap annule.
  • Valeurs de progression (S.P.E.C.I.A.L., rangs et atouts de compétences, PV max, niveau, PE, statistiques dérivées) : double-clic pour éditer, puis une confirmation est demandée à la validation. Les SR (et les jets composites) sont recalculés automatiquement.
  • Sauvegarder : liste les changements et demande confirmation, puis réécrit uniquement les valeurs modifiées dans le fichier .md (le reste du fichier est conservé octet pour octet). La date mise_a_jour du front-matter est actualisée.
  • Les objets d'inventaire s'éditent en Markdown brut (le gras et les apartés sont conservés). Barrer applique la convention ~~objet~~ du projet ; + Objet ajoute une ligne à la fin de la section Inventaire.
  • Repo GitHub : les fiches publiées sont dans la liste en tête de la modale de chargement (tous navigateurs). Les modifications sont mémorisées automatiquement dans ce navigateur ; Publier affiche le récapitulatif puis crée un commit sur le repo (nom de joueur + mot de passe). Si le repo a changé entre-temps, vos modifications sont reportées sur la nouvelle version ; les champs modifiés des deux côtés sont à trancher dans le récapitulatif.
  • Navigateur requis pour l'accès direct aux fichiers : Chrome ou Edge (API File System Access). Ailleurs, l'application bascule sur un sélecteur de fichier classique et la sauvegarde devient un téléchargement.
